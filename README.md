# BerryDB Homebrew Tap

Official Homebrew tap for [BerryDB Desktop](https://github.com/berry-apps/berrydb-desktop) — the lightweight, open-source native macOS database client.

## Installation

Install BerryDB in a single command:

```bash
brew install --cask berry-apps/tap/berrydb
```

Or add the tap first and install:

```bash
brew tap berry-apps/tap
brew install --cask berrydb
```

## Update

To update BerryDB to the latest version:

```bash
brew upgrade --cask berrydb
```
